# 老後資金シミュレーター

父・母の退職後の支出、年金の受け取り開始年齢、寿命、運用のしかたを入れると、何千通りもの運用結果を試算して「想定した寿命まで資金がもつ確率」を出すアプリです。金額の単位はすべて **万円** です。

## すぐに使う（インストール不要）

**▶ https://shisakulab.github.io/rougo-shikin/**

ブラウザで開くだけで使えます。入力した設定は **お使いのブラウザの中にだけ** 保存され、外部には送信されません（計算もすべてブラウザの中で行います）。

初期値と「モデル：〜」のプリセットは、説明用の **架空の世帯** です。ご自身の数字に書き換えて使ってください。

> **ご注意**：このアプリの結果は、入力した仮定に基づく試算で、将来を保証するものではありません。特定の金融商品の売買をすすめるものでもありません。大きな判断の前には、FPなどの専門家に相談してください。

## 自分のパソコンで動かす（設定をファイルに保存したい場合）

以下は、Python を使って自分のパソコンの中だけで動かし、画面で変えた設定を `config.json` に保存する使い方です。`config.json` は次に起動したときに読み込まれます。

## フォルダの中身

| ファイル | 役割 |
|---|---|
| `start.bat` | ダブルクリックでアプリを起動する |
| `server.py` | アプリをこのパソコンの中だけで動かし、設定を `config.json` に保存するプログラム |
| `老後資金シミュレーター.html` | アプリの本体（画面と計算） |
| `config.json` | 画面で設定した値（自動で作られ、更新される。**Git には含めない**） |
| `config.example.json` | 見本の設定。**アプリの初期値とモデルプリセットはここから読み込む**（架空の世帯の値） |
| `index.html` | 公開ページの入口（本体へ移動するだけ） |
| `README.md` | この説明書 |

## 必要なもの

- Windows のパソコン
- **Python 3.8 以上**
  - 入っているかは、コマンドプロンプトで `python --version` と打つと確認できます。
  - 入っていない場合は https://www.python.org/downloads/ からインストールします。インストール画面の最初で **「Add python.exe to PATH」にチェック** を入れてください。
- ブラウザ（Edge または Chrome）

インターネットに接続していなくても動きます（接続していないと、見出しの書体だけ標準の書体になります）。

## 起動のしかた

1. `start.bat` をダブルクリックします。
2. 黒いウィンドウが開き、少しするとブラウザでアプリが開きます。
   - 開かない場合は、ブラウザで http://127.0.0.1:8765/ を開いてください。
3. 画面左の条件を変えると、結果がすぐ計算し直され、`config.json` に保存されます。
   - 保存できたかは、画面上部の「金額の表示」の下に表示されます。

### 終了のしかた

ブラウザのタブを閉じ、**黒いウィンドウも閉じます**（または黒いウィンドウで `Ctrl + C`）。
黒いウィンドウを先に閉じると、それ以降の変更は保存されません。

### コマンドで起動する場合

```
cd （このフォルダの場所）
python server.py --local
```

| オプション | 意味 |
|---|---|
| `--local` | `config.json` を読み込み、画面の変更を `config.json` に保存する（`start.bat` はこれを付けて起動します） |
| `--port 8766` | ポート番号を変える（「ポート 8765 は使用中です」と出たとき） |
| `--no-browser` | ブラウザを自動で開かない |

`--local` を付けずに `python server.py` だけで起動すると、**見本の `config.example.json` で開き、画面で変えても何も保存しません**。`config.json` の個人の数字を出さずに画面を確認したいとき（記事用のスクリーンショットなど）に使います。

### 初期値とモデルプリセットを変える

`config.example.json` を編集します。`params` が初期値、`samples` が「モデル：〜」のプリセット（`params` との差分だけを書く）です。
`params.asOf` より後の年に開くと、西暦の項目（生まれた年・退職する年・旅行や車の年）が同じ年数だけ自動でずれるので、モデル世帯の年齢は変わりません。

### HTMLファイルを直接ダブルクリックした場合

計算はできますが、設定は **`config.json` には保存されず、そのブラウザの中だけ** に保存されます。`config.json` に保存したいときは、必ず `start.bat` から起動してください。
また、この開き方では `config.example.json` を読み込めないため、HTMLの中の予備の初期値で開き、「モデル：〜」のプリセットは表示されません。

## 毎年の見直しのしかた

このアプリは「基準年」の初めを起点に計算します。年齢や時期は西暦（生まれた年・退職する年・車を買う年など）で持っているので、**基準年を進めるだけで年齢や「あと何年」は自動で進みます**。年に1回（年の初めがおすすめ）、次の手順で見直してください。

1. `start.bat` で起動し、「毎年の見直し」にある **「◯年の見直しを始める」** を押します（年が変わっているときだけ表示されます）。基準年が今年になります。
2. 左の条件を今の値に直します。
   - **基準年の初めの金融資産**：その年の初めの実際の残高（預金・国債・投資信託などの合計。旅行・車用に取っておいた国債も含む）
   - **年金の月額**：最新のねんきん定期便の見込み額
   - **生活費・旅行・車の価格・維持費**：今の物価での金額（金額はすべて基準年の価値で入れます）
   - そのほか、退職する年、車を買う年、寿命の想定、運用のしかたなどで変わったもの
3. **「◯年の見直しとして記録」** を押します。その年の資産・確率・この先の予想が `config.json` の `reviews` に保存されます。

### 自動で扱いが変わるもの

| 状況 | 扱い |
|---|---|
| 退職する年が基準年より前 | 退職済み。退職金は受け取り済みで、金融資産に含まれているとみなします |
| 車を買う年が基準年より前 | 購入済み。購入費は計算に入れません（維持費は続きます） |
| 旅行する期間のうち、基準年より前の年 | 行き終わった分として計算に入れません |
| 年齢で決まる項目（年金の受け取り開始、生活費を減らす年齢、運転をやめる年齢など） | 生まれた年から基準年の年齢を出して判定します |

### 記録の見方

「毎年の見直し」の表では、各年の記録を **前回の見直しでの予想** と比べて表示します。

| 表示 | 意味 |
|---|---|
| 予想より良い | 年初の金融資産が、前回の予想の真ん中以上 |
| 予想より悪いが想定内 | 真ん中は下回ったが、運用が悪い方の10%の水準よりは上 |
| 大きく下回る：要見直し | 運用が悪い方の10%の水準も下回った。支出や年金の受け取り開始の見直しを検討 |

表の上には、**次の見直しでの金融資産の目安**（真ん中の予想と、悪い方の10%の水準）も表示されます。見直しで資産を入れ直すと、その年の確率が計算し直されるので、悪い年が続いたときも早めに気づけます。

## 自分の設定をプリセットとして保存する

1. 画面左で条件を設定します。
2. 右上のプリセットの並びにある **「＋ 今の設定を保存」** を押します。
3. 名前（30文字まで）を入れて **「保存」** を押すと、プリセットに追加されます。
   - 同じ名前がすでにあると、上書きするか確認されます。
   - 「モデル：〜」と同じ名前は使えません。
4. 追加したプリセットの **「×」** を押すと削除できます（確認があります）。

- 保存したプリセットは `config.json` の `presets` に入ります（HTMLを直接開いた場合はそのブラウザの中だけ）。
- 保存できるのは30個までです。
- いまの設定とまったく同じプリセットは、色が付いて表示されます。

## config.json の中身

画面で変えれば自動で書き換わるので、普段は手で編集する必要はありません。
手で編集する場合は、**アプリの黒いウィンドウを閉じてから** 編集し、`start.bat` で起動し直してください（開いたまま画面を操作すると、編集内容が上書きされます）。

- `[58, 55]` のように2つ並んでいる項目は **[父, 母]** の順です。
- `true` はオン、`false` はオフです。
- 書式が壊れていると、画面に「config.json を読み込めませんでした」と表示され、直すまで保存しません。
- `config.json` を削除すると、次回は初期設定（モデル：会社員＋専業主婦）で開き、新しく作り直されます。
- 見本から始めたいときは、`config.example.json` をコピーして `config.json` という名前にします。

### 全体の形

```json
{
  "version": 1,
  "savedAt": "最後に保存した日時",
  "view": { ... 表示の設定 ... },
  "params": { ... 今の条件 ... },
  "presets": [
    { "name": "プリセットの名前", "params": { ... params と同じ項目 ... } }
  ],
  "reviews": [
    {
      "asOf": 2026,
      "recordedAt": "記録した日時",
      "assets": 2000,
      "success": 97.7,
      "projection": { "p10": [...], "p50": [...], "p90": [...] },
      "params": { ... 記録したときの条件 ... }
    }
  ]
}
```

`reviews` は「毎年の見直し」で記録したものです。`assets` はその年の初めの金融資産、`success` は資金がもつ確率（%）、`projection` は基準年の年末から1年ごとの金融資産の予想（実際の残高、万円）で、`p10` が悪い方の10%、`p50` が真ん中、`p90` が良い方の10%です。画面から削除できるので、手で編集する必要はありません。

`config.example.json` にだけある項目：

- `samples`：最初から表示される「モデル：〜」のプリセット（`params` との差分だけを書く）
- `links`：画面下に出すリンク。`repo` に GitHub のリポジトリURL（`https://github.com/…`）を入れると「ソースコード」「ご意見・不具合の報告（Issues）」、`article` に解説記事のURLを入れると「解説記事」のリンクが出ます。空なら出ません

`config.json` に書いても使われません。

`presets` の中の `params` は、下の params（条件）と同じ項目です。足りない項目は、アプリの初期値（`config.example.json` の `params` と同じ値）で補われます。

| キー | 意味 | 例 |

| `real` | `true`: 今の価値で表示、`false`: 将来の金額で表示 | `true` |

| `bondLink` | 国債のうち物価連動国債の割合。「実質利回り＋その年のインフレ率」で増え、増えた分に約20%課税 | % | `0` |
| `linkReal` | 物価連動国債の実質利回り（税引前） | % | `0.5` |
| `cashRet` | 現金の金利（`inflVol` が0より大きいときは、変動金利と同じようにインフレ率に追随） | % | `0.2` |

## 「現金＋国債＋株に分けて持つ」の動き

1. 毎年の取り崩し額（生活費＋旅行・車など − 年金 − 収入）を **現金 → 国債 → 株** の順に払います。
2. 年末に、翌年からの取り崩し額に合わせて補充します。
   - **平常時**：株を売って、現金を `cashYears` 年分、国債を `bondYears` 年分に戻します。国債が多すぎる分は株に回します。
   - **暴落時**（株が直近の高値から `crashDD`% 以上下がっている）：株は売らず、国債から現金を補充します。国債が足りなければ株を売ります。
3. 年金が揃うと取り崩し額が小さくなり、必要な現金・国債も減るので、株の比率は自然に高くなります。高くなりすぎるのが不安なら `stockCap` で上限を決めます。

## 計算の前提と注意

- 計算は基準年の初めを起点にします。金額はすべて基準年の価値で入れます。
- 退職までは給与で生活し、資産は運用で増えるだけ（追加の積立なし）とします。運用は基準年から始めます。
- 以前の形式（`ages` `retireIn` `carAt` `travelYears`）の `config.json` を読み込んだ場合は、保存した年を基準年として西暦の形に自動で直します。
- 「分けて持つ」では、退職前は受け取る予定の退職金で退職後の取り崩しをまかなうとみなし、足りない分だけを現金・国債で用意して、残りは今から株で運用します。退職金を受け取った年に、現金・国債を決めた年数分にそろえます。
- 年金は、繰上げ1か月ごとに0.4%減、繰下げ1か月ごとに0.7%増（75歳まで）で計算します。
- 想定寿命を過ぎた人の年金・収入・医療費はなくなり、生活費は `single` の割合になります。
- `survivor` が `true` なら、一人になった後の遺族厚生年金を残された方に足します。65歳以上は「亡くなった方の `kosei` × 3/4 − 自分の `kosei`」（差額がプラスのときだけ）、65歳未満は「自分の老齢年金」と「亡くなった方の `kosei` × 3/4（母が40歳以上なら中高齢寡婦加算61.1万円を加算）」の多い方とします。`kosei` は繰上げ・繰下げの増減を反映しない本来の額で計算し、遺族厚生年金は非課税なので `netRate` はかけません。遺族基礎年金（18歳未満の子がいる場合）は含みません。
- 運用益や配当の税金（`jpTaxable` 以外）、住宅の修繕費、介護の一時費用（住宅改修など）は含みません。必要なら `medical` や `living` に上乗せしてください。
- 同じ条件なら毎回同じ結果になるよう、乱数を固定しています。
- **この結果は仮定に基づく試算で、将来を保証するものではありません。** 大きな判断の前には、FPなどの専門家に相談してください。

| 症状 | 対処 |
|---|---|
| 「Python が見つかりません」と出る | 「必要なもの」を見て Python をインストールする（PATHのチェックを忘れずに） |
